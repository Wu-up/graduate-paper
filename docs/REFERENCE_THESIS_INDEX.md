# Reference Thesis Index

本文件记录三篇参考硕士论文在本仓库中的写作参考定位。参考论文只用于私人学术写作范式学习，不作为正文技术事实的替代引用来源。

## Copyright And Use Rules

- 原论文仅作为私人学术写作参考。
- 不提交完整全文到公开 GitHub 仓库。
- 不复制连续原文。
- 不使用参考论文替代真实技术文献引用。
- 正文中的技术事实仍必须引用对应原始学术来源。
- Playbook 和正式正文只提炼写作结构、论证功能和证据组织方式，不迁移参考论文的具体句子。
