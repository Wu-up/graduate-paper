# Facts And Numbers

All thesis facts, numbers, claims, and publication statuses must be entered here before they appear in formal body text.

## PAPER_REPORTED

Facts explicitly reported by an existing paper, manuscript, or author-confirmed draft.

- None recorded in P-000.

## EXPERIMENTALLY_VERIFIED

Facts verified from local experiment logs, result JSON/CSV files, frozen gates, or other reproducible artifacts.

- None recorded in P-000.

## THESIS_PLACEHOLDER

Template-only placeholders used to test compilation and layout.

- Current thesis title in LaTeX files is placeholder text.
- Current abstract text is placeholder text.
- Current chapter body text is placeholder text.
- Current figures and tables are placeholder tests.
- Current bibliography entries are public test references for formatting only.

## Rules

- Do not move an item from `THESIS_PLACEHOLDER` into formal prose.
- Do not fill missing values from memory or expectation.
- Keep unsupported claims blank until a source is attached.
- Preserve invalid or rejected evidence separately if encountered later.
